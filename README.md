# TipFromTrade（TFT）

![TipFromTrade logo](assets/tft-logo.png)

TipFromTrade 是一个面向 BNB Smart Chain 创作者的代币发行与内容激励项目，目标是让交易税的一部分透明地回流给相关内容创作者、社区讨论者和项目公共金库。

> 项目仍在建设和测试阶段。页面中的代币、结算、打赏与回购数据在正式链上部署和独立审计完成前均不代表真实执行结果，也不构成收益承诺或投资建议。

## 核心机制

社区代币计划采用固定的 1% 买入税和 1% 卖出税。税费进入对应代币的独立金库后，按以下方向记账：

- **70% 创作者打赏**：发币时可绑定币安广场创作者；暂未绑定时，该份额留在代币专属金库等待后续核验。
- **20% TFT 回购销毁金库**：汇入统一金库，计划用于回购并销毁 TFT。
- **10% 社区内容激励**：奖励围绕相关代币产生的优质讨论内容。

结算按固定五分钟周期检查。若本周期内累计税费达到 0.1 BNB，则在该周期结束时进入结算流程；未达到阈值则继续累计。连续 30 分钟没有新金库收入时，也会在轮末触发一次余额结算检查。门槛直接按原生 BNB 计算，不依赖 BNB/USD 价格。

更完整的说明见 [机制说明](docs/mechanism.md) 和 [公开信息与安全边界](docs/security-and-status.md)。

## 代币市场与税收看板

官网工作台已加入“代币市场”页面。官方 TFT 和通过本站金库工厂发射的社区代币会在这里集中展示：

- 代币名称、符号、合约地址、市值、24 小时交易量和价格；
- 累计确认税收，以及创作者奖励、币安广场内容打赏和 TFT 回购销毁三项分配；
- 官方 TFT 按 80% 内容激励、20% 回购销毁单独展示；
- 社区代币按 70% 创作者、10% 内容激励、20% 回购销毁展示。

行情计划每 30 秒刷新，并使用 GeckoTerminal、DEX Screener 和 Flap 数据作为多路来源。链上金库事件是税收与分配金额的依据；行情源延迟、限流或尚未收录时显示“—”，不会用虚构数值代替。

## 多语言界面

官网右上角提供语言选择器，支持简体中文、繁體中文、English、日本語和한국어。导航、机制说明、发币、行情、结算、资金透明、项目文档和币安广场讨论档案均纳入完整翻译；所选语言保存在当前浏览器中，刷新页面或切换工作台板块后仍会保持。中文界面统一使用“币安广场”全称，避免把“广场”误解为其他平台。

## 打赏任务与运营权限

公开工作台展示打赏任务编号、来源代币、奖励对象、金额以及“待打赏、处理中、等待核验、已核验”等状态，但不会向普通访客返回币安广场付款入口、付款编号、完整凭证地址或运营备注。

运营人员通过独立的受保护入口处理任务。运营身份由 Cloudflare Access 在服务器侧验证；只有允许名单中的账户能够查看原帖链接、登记付款、提交脱敏凭证和标记核验结果。前端隐藏按钮不构成权限控制，未通过验证的请求会由服务端拒绝。

币安广场投稿审核也已迁入同一受保护运营区。公开页面不接收管理令牌，旧的公开审核接口已经停用；投稿与图片上传采用服务端限流，上传封面仅接受经过文件签名校验的 PNG、JPEG、WebP 和 GIF。

币安广场站内付款与链上金库转账分别记录。受保护的后台将流程拆为“托管钱包签名转入运营方币安 BSC 充值地址、核对币安到账、完成广场原生打赏并登记凭证”三段。只有付款编号和脱敏凭证完成核验后，公开状态才会更新为“已核验打赏”。网站不保存钱包私钥、币安密码或登录 Cookie。
## 当前状态

- 官网已启用 CSP、HSTS、防嵌入、MIME 嗅探防护、来源策略和浏览器权限限制等安全响应头。

- 真实资金启用前需要完成独立合约审计、权限设计、多签或硬件钱包方案及主网分叉测试。

# 公开信息与安全边界

## 当前阶段

TipFromTrade 目前处于产品建设和合约验证阶段。官网可访问，但以下能力在完成独立审计和主网验证前不应视为已经启用：

- 真实代币发行；
- 自动闪兑与分账；
- 自动币安广场打赏；
- TFT 回购与销毁；
- 以真实资金运行的无人值守结算。

官网中的“代币市场”已经上线，但在金库工厂和索引服务接入主网前，社区代币列表与税收数据会保持等待状态。行情数据来自第三方公开服务，可能出现延迟、限流或暂未收录；页面在这些情况下显示“—”，不会把未知值写成零。

官网当前启用了内容安全策略、HTTPS 强制策略、防嵌入与 MIME 嗅探防护等响应头。打赏任务、投稿审核与合约部署操作位于 Cloudflare Access 保护的运营区；公开页面不保存或接收运营审核令牌。公开投稿与图片上传由服务端限制频率，上传封面会检查文件类型和实际文件签名。

## 公开仓库包含什么

本仓库包含项目介绍、机制说明和品牌素材，方便社区了解和引用项目。它不包含：

- 钱包私钥、助记词或签名材料；
- Cloudflare、GitHub 或其他平台的访问令牌；
- 运营凭证和环境变量；
- 网站数据库、投稿记录或运营日志；
- 未审计的完整应用和自动结算源码。

## 风险提示

代币、智能合约和链上交易具有技术、市场和流动性风险。TipFromTrade 的机制描述是产品设计，不是固定收益、保本或价格承诺。请只通过官网公布的入口核对信息，并在交互前自行验证合约地址和交易内容。

## 安全报告

如发现网站、合约或品牌冒用问题，请通过项目 X 账号 [@TipFromTrade](https://x.com/TipFromTrade) 联系。请勿在公开 Issue 中提交私钥、助记词、令牌或其他敏感信息。
